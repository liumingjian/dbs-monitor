# Domain Docs

This repository uses a single-context domain layout.

Before exploring a task, read `CONTEXT.md` and the relevant decision documents in `docs/design/`. Use the vocabulary defined in `CONTEXT.md` in code, tests, issue titles, and handoffs. Surface conflicts with a frozen design decision instead of silently changing it.

The repository does not currently use `docs/adr/`; frozen decisions live in `docs/design/` and must be amended only through an explicit decision record or a documented closeout supplement.
