# 17 · 用户与角色管理与实例接入的产品语义

> 出处:[S2 · 用户与角色管理与实例接入的产品语义](https://github.com/liumingjian/dbs-monitor/issues/38)(地图 [#36](https://github.com/liumingjian/dbs-monitor/issues/36) 子票)。
> 定位:R1 有意划出(原去向 R6)、至今零产品决策的两块——用户与角色管理页、实例接入页——的 MVP 产品语义。三档角色的存在(ADR-09)、凭据加密与 Agent 令牌语义([`13`](13-credential-encryption-rotation-and-revocation.md))、首启管理员口令(T8)均为输入边界,本文不重议。
> 状态:2026-08-05 HITL 拍板,冻结。推翻任何一条须新开决策记录。

---

## 0. 一句话结论

用户只有本地账号、只停用不删除;口令一律「随机生成、一次性回显」;唯一角色守卫是「启用态平台管理员 ≥1」外加禁止自我停用/降级。实例接入不新开顶层区、用户管理以收窄命名新开第五顶层区;创建实例「连接测试+版本门都过才落库」;移除按「配置立删/告警连带关闭/样本随 TTL」三层分收;接触秘密的写操作全归平台管理员,已有实例的元数据编辑下放告警管理员。

---

## 1. D1 · 用户来源:仅本地账号

MVP 只做本地账号。首启管理员(T8:随机口令、打印一次)是种子用户;其余用户全部由平台管理员在用户管理页手工创建,创建输入为**用户名 + 角色**两项,初始口令由服务端随机生成、一次性回显(见 D3)。

不做 LDAP / AD / SSO / OIDC,不做自助注册,不做邮箱邀请流。外部目录集成是典型的后续需求,显式延后(见 §11),防止无意重新引入。

## 2. D2 · 用户生命周期:只停用不删除

- 用户可**停用 / 重新启用**;停用立即生效:不可登录,现有会话全部失效。
- **不做硬删除**。告警确认/忽略、凭据更新等操作留痕都带操作人;删除用户会让历史留痕的归因悬空。一句话理由:**操作留痕永远可归因**。
- 用户名全局唯一、创建后不可改,不做回收复用——同一个名字在全部历史里只指向一个人。

## 3. D3 · 口令机制:随机生成、一次性回显

- **创建用户与管理员重置他人口令**,一律由服务端随机生成口令、弹窗一次性回显(复制后不再显示)。与 T8 首启口令同构;管理员不能自拟他人口令,口令强度由生成器保证。
- **不做「下次登录强制改密」**——它需要新增拦截态与专页,内网小团队收益低。
- 用户**自改口令**入口在顶栏用户菜单,须验证旧口令。
- 口令策略只设**最小长度**(具体数值属参数级,留片⑧ spec 的 Implementation Decisions)。不做复杂度规则、定期过期、口令历史查重——过期策略在内网监控平台是误报之源:到期无人改 → 账号锁死 → 看不到告警。

## 4. D4 · 角色变更守卫

- 唯一不变式:**启用状态的平台管理员始终 ≥ 1**。会让它跌破的停用/降级操作被拒绝并说明原因。
- 附加规则:**任何用户不得停用或降级自己**(即使不是最后一名)——防误操作;双管理员交接时互相操作,代价可接受。
- 首启管理员**无任何特殊地位**:就是普通平台管理员,同受同一守卫,可被(其他管理员)停用或降级。

## 5. D5 · 页面树落位

ADR-09 否决「系统管理」顶层区的理由是它会变成堆放处;它否决的是**无边界命名**,不是禁止新顶层区——它自己就以收窄命名新增了「告警设置」。延续同一方法论:

- **实例接入不新开顶层区**:登记入口是「实例列表」页的**新建实例**按钮;编辑/凭据/Agent/移除住在**实例维度的「接入设置」页**(从列表行与实例工作台均可进入,见 D9)。
- **用户与角色管理新开第五顶层区**,命名收窄为「**用户管理**」,仅装用户/角色一类对象。顶层页面树从四区变五区:实例列表 / 全局告警 / 实例工作台 / 告警设置 / **用户管理**。

## 6. D6 · 接入校验:创建即验,失败不落库

- **创建实例**提交元数据 + PG 凭据,服务端**连接测试与版本门(被监控 PG ≥13,[`06`](06-metric-dictionary-and-collection-plan.md) §5.1)都通过才落库**;任一失败即拒绝创建,并给出具体分类原因(网络不通 / 认证失败 / 版本 <13,错误分类服从 [`13`](13-credential-encryption-rotation-and-revocation.md) D9 的稳定映射)。
- **编辑**时,凡影响连接的字段(host / port / database)同样「测试成功才提交」,重测使用库内既存凭据;纯展示字段(name 等)不测。与 [`13`](13-credential-encryption-rotation-and-revocation.md) D4 的凭据更新流程同构。
- 由此得到不变式:**库里不存在从未连通过的实例**——`DB_UNREACHABLE` / `NO_DATA` 永远意味着「变坏了」而非「从没好过」,版本门的「接入即拒」字面成立。
- 显式接受的代价:防火墙未开通前无法「先登记占位」(见 §11)。

## 7. D7 · 实例移除:三层分收

| 层 | 处置 | 依据 |
|---|---|---|
| 配置层 | 实例记录、采集计划、凭据密文、Agent 登记与令牌**立即删除**,采集即刻停止 | 「移除」字面语义 |
| 告警层 | **全部未恢复告警**(PENDING / FIRING / NO_DATA)随移除**连带关闭并留痕关闭原因**;告警历史与处置留痕**保留** | 把 ADR-07「NO_DATA 随移除连带关闭」推广到全部未恢复状态;留痕归因永远成立(与 D2 同构) |
| 时序样本 | **不同步删除**,随 30 天分区 TTL 自然过期 | 窄表按天分区([`04`](04-metric-storage-model.md)),删单实例历史 = 跨全部分区大 DELETE,不值得为低频操作写专门清理 |

重新接入同一个库 = 全新实例,不继承任何历史。移除的确认流程:**输入实例名双确认**。

## 8. D8 · 写权限分配

「可见性不收窄、写能力收窄」不变式照旧:两页对全部角色可见,无权控件置灰并说明所需角色。写能力分配:

| 操作 | 最低角色 |
|---|---|
| 创建实例(必含凭据)、更新 PG 凭据、Agent 登记/轮换/吊销/停用、移除实例 | 平台管理员 |
| **已有实例**的元数据编辑(name / host / port / database,连接字段重测用既存凭据,不提交新凭据) | **告警管理员** |
| 用户管理页全部写操作 | 平台管理员 |

边界一句话:**接触秘密的动作全归平台管理员**。创建实例因原子包含凭据录入(D6),归平台管理员,不因元数据下放而拆分——避免「能建实例但不能填凭据」的断头流程,也不违 [`13`](13-credential-encryption-rotation-and-revocation.md) D4「凭据提交人是平台管理员」。

## 9. D9 · 「接入设置」页构成:四分区单页

从实例列表行与实例工作台均可进入,单页四分区:

1. **元数据区**:name / host / port / database;连接字段改动提交即重测(D6)。
2. **PG 凭据区**:只读显示当前监控账号 **username**([`13`](13-credential-encryption-rotation-and-revocation.md) D9 禁名单不含 username;排障 `AUTH_FAILED` 时需要它)+「更新凭据」表单(username + password 双填);password 永不回显,无任何「查看」控件。
3. **Agent 区**:状态呈现 [`13`](13-credential-encryption-rotation-and-revocation.md) D5 的生命周期事实(从未登记 / 应在线 / 已吊销 / 已停用);操作 = 登记 / 轮换 / 吊销 / 停用 / 重新启用;签发与轮换成功后弹窗**一次性**显示令牌(复制按钮 +「关闭后不再显示」警示),并附安装指引(agent 包下载入口、token 落盘路径与权限、重启命令)。
4. **危险区**:移除实例,输入实例名双确认(D7)。

## 10. D10 · 用户管理页构成(由 D1–D4 组合推导)

- **用户列表**:用户名 / 角色 / 启用状态 / 创建时间。
- **创建用户**弹窗:用户名 + 角色;成功后一次性回显随机初始口令(D3)。
- **行操作**:停用 / 启用、重置口令、变更角色——均受 D4 守卫约束,被拒时说明原因。

## 11. 否决与延后记录

| 被否决 / 延后 | 为什么 |
|---|---|
| LDAP / AD / SSO / OIDC | 私有化内网单租户的典型后续需求,MVP 本地账号足够;延后而非永决 |
| 自助注册、邮箱邀请流 | 用户由管理员创建,无自助场景 |
| 用户硬删除、改名、用户名回收 | 操作留痕的归因会悬空(D2) |
| 「下次登录强制改密」 | 新增拦截态与专页,内网小团队收益低(D3) |
| 口令复杂度规则 / 定期过期 / 历史查重 | 过期策略在内网监控平台是误报之源:锁死账号 → 看不到告警(D3) |
| 实例离线登记(先占位后连通) | 破坏「库里不存在从未连通过的实例」不变式,且让版本门「接入即拒」变形(D6) |
| 全局审计日志页 | 操作留痕已随各对象详情逐条可查;与 ADR-09 否决「全局通知记录查询页」同构 |
| 实例批量导入(CSV / 批量 API) | 目标规模 50 实例,逐个手工接入可接受 |
| 实例级授权 | R2 已划出([R2 地图 #15](https://github.com/liumingjian/dbs-monitor/issues/15)),重申不回收 |

## 12. 术语澄清(入 `CONTEXT.md`)

- **联系人 ≠ 用户**:联系人是告警域的投递目标(ADR-07),用户是登录主体;创建用户不自动建联系人,创建联系人不要求存在用户。
- **登记 Agent ≠ 接入实例**:`CONTEXT.md` 已有的 **Agent enrollment** 条目继续成立——`agent_expected` 独立于实例存在,接入实例不隐含登记 Agent。
