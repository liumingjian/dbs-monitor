# 监控平台产品信息架构草案 v0.1

> 目标：定义 PostgreSQL 监控平台 MVP 的页面结构、页面职责、导航关系和排障路径。  
> 产品定位：私有化 PostgreSQL 运维排障工作台。  
> 参考依据：[`../research/aliyun-rds/aliyun-rds-pg-monitor-feasibility-report.md`](../research/aliyun-rds/aliyun-rds-pg-monitor-feasibility-report.md)、[`01-pg-mvp-metric-dictionary.md`](01-pg-mvp-metric-dictionary.md)、[`02-alert-rule-model-draft.md`](02-alert-rule-model-draft.md)。  
> 当前阶段：信息架构草案，不是完整 PRD、交互原型或视觉设计。

---

## 1. 设计原则

### 1.1 不复刻阿里云复杂导航

阿里云 RDS 控制台服务于云产品全家桶，导航复杂度较高。自研平台首版应聚焦私有化 / AP 场景下的数据库运维排障，不应照搬云控制台结构。

### 1.2 以实例为核心对象

首版围绕 PostgreSQL 实例组织信息：

```text
实例
→ 指标
→ 会话 / 阻塞
→ 性能事件
→ 告警
→ 采集状态
```

用户进入平台后的主要任务不是浏览产品功能，而是判断某个实例是否健康、异常从何而来、下一步看哪里。

### 1.3 以排障路径组织页面

页面应支持以下连续问题：

1. 实例是否可用？
2. 数据是否新鲜可信？
3. 主机资源是否异常？
4. 数据库负载是否异常？
5. 是否有慢 SQL、长事务、锁等待、阻塞链？
6. 是否有复制延迟？
7. 是否有性能事件？
8. 是否触发告警？
9. 下一步应该看哪个证据？

### 1.4 空状态必须解释原因

所有页面必须区分：

- 加载中
- 暂无样本
- 当前时间范围无数据
- 数据过期
- 数据库不可达
- 无权限
- Agent 离线
- 扩展未安装
- 功能未启用
- 当前版本不支持
- 当前实例角色不适用
- 采集异常

不要只显示空图表或空表格。

## 2. 信息层级

建议采用三层结构。

```text
平台级
├── 实例列表
├── 全局告警
├── 全局性能事件，P1/P2
└── 采集管理，P1/P2

实例级
├── 实例总览
├── 标准监控
├── 会话与阻塞
├── 性能事件
├── 告警
└── 采集管理

详情级
├── 指标详情
├── 会话详情
├── 阻塞链详情
├── 性能事件详情
├── 告警详情
└── 采集能力详情
```

首版可以弱化平台级高级能力，但必须保留实例列表和实例工作台的清晰边界。

## 4. 页面职责

### 4.1 实例列表

#### 页面目标

帮助用户从多个 PostgreSQL 实例中快速发现需要关注的对象。

#### 主要问题

- 哪些实例异常？
- 哪些实例正在告警？
- 哪些实例采集不正常？
- 哪些实例最近没有数据？

#### 核心信息

- 实例名称
- 地址 / 端口 / 环境
- PostgreSQL 版本
- 实例角色
- 健康状态
- 当前告警数
- 当前性能事件数
- Agent 状态
- 最近采集时间
- 数据新鲜度

#### 主要入口

- 平台首页
- 全局搜索
- 告警通知回跳

#### 主要出口

- 实例总览
- 当前告警
- 采集管理

---

### 4.2 实例总览

#### 页面目标

回答“这个实例现在是否健康，下一步应该看哪里”。

#### 核心模块

1. 可用性与采集状态
   - 实例连通性
   - 主动探针延迟
   - 最近采集时间
   - Agent 状态

2. 当前告警摘要
   - critical / warning 数量
   - 最近触发告警
   - 未恢复告警

3. 核心资源摘要
   - CPU
   - 内存
   - 磁盘
   - IO
   - 网络

4. 数据库负载摘要
   - 总连接数
   - 活跃连接数
   - TPS
   - 临时文件写入
   - 长事务
   - 锁等待

5. 复制状态摘要
   - 当前角色
   - 复制连接状态
   - 复制延迟
   - Replication slot 积压

6. 近期性能事件
   - 触发中事件
   - 最近恢复事件
   - 建议动作摘要

7. 快速排障入口
   - 查看标准监控
   - 查看会话与阻塞
   - 查看告警详情
   - 查看采集状态

#### 注意

实例总览不应承载完整图表大盘。它应以摘要、异常和入口为主。

---

### 4.3 标准监控

#### 页面目标

回答“指标趋势如何，异常从什么时候开始”。

#### 核心模块

- 时间范围选择
- 数据粒度选择
- 图表列数 / 布局
- 光标联动
- 资源指标区
- 数据库指标区
- 复制指标区
- 指标详情说明

#### 指标分组

```text
资源指标
├── CPU
├── 内存
├── 磁盘空间
├── 磁盘 IO / IOPS
└── 网络流量

数据库指标
├── 连接数
├── 活跃连接数
├── idle in transaction
├── TPS
├── 提交 / 回滚
├── 读写行数
├── 临时文件
├── 长事务
├── 锁等待
├── 阻塞会话
└── 2PC

复制指标
├── 实例角色
├── 复制连接状态
├── 复制延迟
├── WAL 延迟
└── Replication slot 积压
```

#### 页面出口

- 指标详情
- 会话与阻塞，继承实例和时间范围
- 性能事件，查看相关事件
- 告警详情，查看触发记录
- 采集管理，查看数据不可用原因

---

### 4.4 会话与阻塞

#### 页面目标

回答“当前哪些会话、事务或锁等待正在影响数据库”。

#### 核心模块

1. 活跃会话列表
2. 长事务列表
3. 锁等待列表
4. 阻塞链视图
5. 会话详情

#### 典型字段

- PID
- 用户名
- 数据库名
- 客户端地址
- 状态
- SQL 文本，默认截断和脱敏
- 查询开始时间
- 事务开始时间
- 查询持续时间
- 事务持续时间
- 等待事件类型
- 等待事件
- 阻塞源 PID
- 阻塞链摘要

#### MVP 操作边界

首版默认只读排障，不开放：

- kill session
- cancel query
- 批量终止会话
- 自动处理阻塞

如未来开放，必须增加权限、二次确认、审计和风险提示。

---

### 4.5 性能事件

#### 页面目标

回答“平台识别出了哪些异常、原因摘要和建议动作”。

#### 事件来源

性能事件不是 PostgreSQL 原生事件，而是基于以下数据派生：

- 指标时序
- 会话 / 阻塞快照
- 日志，后续
- 告警规则或事件规则
- 采集状态

#### 核心模块

- 触发中事件
- 已恢复事件
- 已确认 / 已忽略事件
- 事件详情

#### 事件字段

- 事件 ID
- 实例
- 级别
- 类型
- 状态
- 首次发生时间
- 最近发生时间
- 持续时长
- 触发指标
- 原因摘要
- 建议动作
- 关联指标图
- 关联会话 / 阻塞 / 日志
- 关联告警

#### 与告警的区别

| 对象 | 重点 |
|---|---|
| 告警 | 用户配置规则、通知、确认、恢复、审计 |
| 性能事件 | 平台识别异常、原因摘要、建议动作、证据链 |

可能出现：

- 有告警但没有性能事件。
- 有性能事件但没有配置告警。
- 同一异常同时关联告警和性能事件。

---

### 4.6 告警

#### 页面目标

回答“哪些规则触发了通知，是否恢复，是否有人处理”。

#### 子页面

```text
告警
├── 告警规则
├── 当前告警
├── 告警历史
└── 告警详情
```

#### 告警规则

展示：

- 规则名称
- 指标
- 作用范围
- 条件
- 周期 / 窗口 / 连续次数
- 严重级别
- 启停状态
- 联系人组
- 当前告警数
- 所需能力是否满足

#### 当前告警

展示：

- 严重级别
- 实例 / 资源
- 规则名称
- 触发值
- 阈值
- 首次触发时间
- 持续时间
- 当前状态
- 是否静默 / 维护窗口 / 抑制
- No Data 原因

#### 告警历史

展示：

- 触发时间
- 恢复时间
- 持续时长
- 触发值
- 阈值
- 规则快照
- 通知结果
- 确认记录

#### 告警详情

应关联：

- 触发指标图
- 规则快照
- 通知记录
- 采集状态
- 性能事件
- 会话 / 阻塞快照，若有

---

### 4.7 采集管理

#### 页面目标

回答“数据是否可信，为什么某些指标或功能不可用”。

#### 核心模块

1. 采集总状态
   - 数据库连接状态
   - 最近成功采集时间
   - 数据新鲜度
   - 采集失败数

2. Agent 状态
   - 在线 / 离线 / 未安装
   - 最近心跳
   - 版本
   - 权限状态
   - 受影响指标

3. 数据库连接与权限检查
   - 连接是否成功
   - PostgreSQL 版本
   - 是否主库 / 备库
   - 是否具备 `pg_monitor`
   - 系统视图读取状态
   - 复制状态读取权限

4. 扩展 / 插件能力
   - `pg_stat_statements`
   - `pgstattuple`
   - 其他扩展

5. 指标采集状态
   - 指标 ID
   - 最近采集时间
   - 当前状态
   - 失败原因
   - 所需能力

6. 采集配置
   - 采样周期
   - 是否启用 Agent 指标
   - 是否启用日志采集，后续
   - 是否启用增强监控，后续

## 5. 页面间关联

### 5.1 关键跳转关系

| 来源 | 目标 | 传递上下文 |
|---|---|---|
| 实例列表异常状态 | 实例总览 | instance_id |
| 实例总览资源异常 | 标准监控 | instance_id、metric_id、time_range |
| 实例总览锁等待 | 会话与阻塞 | instance_id、time_range、filter=lock_wait |
| 标准监控连接数突增 | 会话与阻塞 | instance_id、time_range、metric_id |
| 标准监控复制延迟 | 性能事件 / 复制指标详情 | instance_id、metric_id、time_range |
| 当前告警 | 告警详情 | alert_instance_id |
| 告警详情 | 标准监控 | instance_id、metric_id、trigger_time_range |
| 告警详情 | 会话与阻塞 | instance_id、trigger_time_range、related_snapshot |
| 性能事件详情 | 标准监控 | instance_id、metric_id、event_time_range |
| 性能事件详情 | 告警详情 | alert_instance_id |
| 指标空状态 | 采集管理 | instance_id、metric_id |
| Agent 离线提示 | 采集管理 | instance_id、agent_id |

### 5.2 上下文继承原则

页面跳转应尽量继承：

- 实例
- 时间范围
- 指标
- 告警实例
- 性能事件
- 会话快照时间
- 过滤条件

否则用户需要在每个页面重新定位问题，排障路径会中断。

## 6. 关键用户路径

### 6.1 日常巡检

```text
实例列表
→ 实例总览
→ 查看可用性、资源、负载、复制和告警摘要
→ 进入标准监控
→ 查看异常指标趋势
→ 返回总览或进入事件 / 会话详情
```

成功标准：

- 用户能判断实例是否在线。
- 用户能判断数据是否新鲜。
- 用户能看到是否有未恢复告警。
- 用户知道下一步看标准监控、会话阻塞还是采集管理。

---

### 6.2 CPU 或连接数异常排障

```text
告警通知 / 总览异常卡片
→ 告警详情或标准监控
→ 定位异常开始时间
→ 会话与阻塞
→ 筛选活跃会话、长事务、等待事件
→ 查看会话详情
→ 回看关联指标和性能事件
```

关键要求：

- 从告警跳转到标准监控时自动定位触发时间。
- 从标准监控跳转到会话与阻塞时继承时间范围。
- 会话详情展示 SQL 时必须截断和脱敏。

---

### 6.3 锁等待与阻塞排障

```text
总览 / 性能事件 / 告警
→ 会话与阻塞
→ 锁等待列表
→ 阻塞链
→ 阻塞源会话详情
→ 查看 SQL、用户、数据库、客户端、持续时间
→ 查看关联指标趋势
```

首版只读，不直接处理阻塞。

---

### 6.4 告警处理

```text
告警通知
→ 告警详情
→ 查看触发条件、触发值、阈值、持续时间
→ 查看关联指标图
→ 查看是否 No Data、Agent 离线、维护窗口
→ 跳转会话 / 阻塞或性能事件
→ 确认、备注或忽略
→ 查看恢复记录
```

关键要求：

- 告警详情必须解释为什么触发。
- 告警详情必须展示规则版本或规则快照。
- 恢复记录必须可追踪。

---

### 6.5 数据缺失或能力不可用排查

```text
空图表 / 空表格 / 指标不可用提示
→ 查看不可用原因
→ 采集管理
→ 检查 Agent、数据库连接、权限、扩展、版本
→ 查看受影响指标
→ 修复后等待采集恢复
```

这是私有化场景下非常重要的路径。用户不能把“平台没采到数据”误判为“数据库正常”。

## 7. 统一状态模型

### 7.1 健康状态

| 状态 | 说明 |
|---|---|
| 正常 | 数据新鲜，关键指标正常，无未恢复严重告警 |
| 异常 | 存在异常指标、事件或告警 |
| 告警中 | 有未恢复告警 |
| 已恢复 | 曾触发异常或告警，但已恢复 |
| 未知 | 数据不足，无法判断健康状态 |

### 7.2 数据状态

| 状态 | 说明 |
|---|---|
| 加载中 | 请求未完成 |
| 暂无样本 | 指标可用，但当前尚无样本 |
| 当前时间范围无数据 | 换时间范围可能有数据 |
| 数据过期 | 最近样本超出新鲜度阈值 |
| 采集失败 | 采集任务失败 |
| 数据库不可达 | 数据库连接失败 |
| Agent 离线 | Agent 指标不可用 |
| 无权限 | 监控账号权限不足 |
| 功能未启用 | 扩展、日志或采集功能未开启 |
| 版本不支持 | 当前 PG 版本不支持 |
| 不适用 | 当前角色或拓扑不适用 |

### 7.3 告警状态

与告警模型保持一致：

- OK
- PENDING
- FIRING
- NO_DATA
- SUPPRESSED
- RECOVERED

UI 可展示为中文：

- 正常
- 待持续
- 告警中
- 无数据
- 已抑制 / 已静默
- 已恢复

## 8. 角色与权限边界

首版至少区分以下角色。

| 角色 | 能力 |
|---|---|
| 只读运维人员 | 查看实例、指标、会话、事件、告警历史 |
| 告警配置人员 | 创建、修改、启停告警规则，配置通知策略 |
| 数据库管理员 | 查看更完整会话信息，未来可执行高风险操作 |
| 平台管理员 | 配置采集、Agent、权限、实例接入 |

### 8.1 敏感能力

以下能力需要特殊权限或首版不开放：

- 查看完整 SQL 文本
- 查看敏感客户端信息
- 修改采集配置
- 修改告警规则
- 绑定或替换 Agent
- cancel query
- terminate session
- 批量终止会话

首版建议不开放 cancel / terminate。

## 9. 与指标字典的依赖

信息架构依赖指标字典提供：

- 指标 ID
- 指标名称
- 指标定义
- 单位
- 聚合方式
- 采集频率
- 数据来源
- 是否需要 Agent
- 是否需要扩展
- 所需权限
- 适用角色
- 缺数语义
- 是否可告警
- 是否可生成事件

典型影响：

- 标准监控图表来自指标字典。
- 实例总览摘要来自 P0 指标。
- 告警规则可选指标来自可告警指标。
- 指标不可用提示来自指标前置条件。
- 采集管理的受影响指标来自指标依赖关系。

---

## 10. 与告警模型的依赖

信息架构依赖告警模型提供：

- 告警规则
- 当前告警实例
- 告警历史事件
- 恢复记录
- 确认 / 忽略记录
- 通知记录
- No Data 状态
- 静默 / 维护窗口 / 抑制状态
- 规则版本快照

告警详情需要至少关联：

```text
实例 ID
指标 ID
告警规则 ID
告警实例 ID
触发时间范围
触发值
阈值
规则版本
通知记录
采集状态
```

如果未来要在告警详情中展示会话或阻塞现场，需要保存触发时快照，否则事后无法复现。

---

## 11. 可延后页面和能力

以下内容不建议进入首版 IA，或只保留占位入口：

1. 独立增强监控 / 高频监控页面。
2. 完整性能洞察。
3. SQL 画像与 SQL 指纹中心。
4. 精确膨胀分析。
5. 自动空间回收建议。
6. SQL 自动优化和收益量化。
7. 会话操作中心。
8. 复杂通知编排中心。
9. 多数据库统一抽象视图。
10. 自动根因分析中心。

增强监控可先作为标准监控中的短时间窗口和高频候选能力，不必首版独立成复杂页面。

## 12. 待确认事项

1. 平台首页是否直接采用实例列表，还是需要独立 Dashboard。
2. 全局性能事件是否进入首版，还是只做实例级性能事件。
3. 全局告警是否首版必须，还是先从实例级告警开始。
4. 实例总览中的健康状态如何加权：告警、事件、采集状态、指标异常各占什么权重。
5. 标准监控是否支持用户自定义图表布局。
6. 增强监控是否首版作为标准监控的时间粒度选项，还是后续独立页面。
7. 会话列表是否需要保存历史快照，还是只展示当前瞬时状态。
8. 性能事件和告警是否共享确认 / 忽略语义。
9. 采集配置是否允许普通用户修改，还是仅平台管理员可见。
10. SQL 文本脱敏规则由平台统一处理，还是由采集端处理。
